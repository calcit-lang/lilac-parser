# Migrate lilac-parser to Calcit 0.14.11

- Migrated from the legacy `compact.cirru` / `calcit-test` / `setup-cr` workflow to a single canonical `calcit.cirru` on the Calcit 0.14.11 toolchain (`@calcit/procs` 0.14.11), removing the retired `compact.cirru` and `package.cirru`.
- Replaced the archived `calcit-test` dependency with built-in assertions (`deftest`/`testing`/`is` shims over `assert`) and migrated strict `Macro` contracts and dynamic map/collection access (`&map:*`, `&list:*`, `map-indexed-dynamic`), plus the `reel.typed` integration.
- Aligned the provider chain to reel 0.6.20, respo-ui 0.7.20, respo-router 0.8.14, respo-markdown 0.4.34, alerts 0.10.31, respo-feather 0.4.12, Respo 0.16.97, and js-ffi 0.1.16.
- Hardened CI with `setup-calcit`, strict Caps, immutable action pins, least privilege, and a separate deployment job; the parser tests run natively and in JavaScript, and the Vite production build is verified.
